# WezTerm Lua設定 - キーバインド一覧（Mac版）

**Leaderキー**: `Ctrl + q` (タイムアウト: 2秒)

---

## ワークスペース操作

| キー | 説明 |
|------|------|
| `Leader + w` | ワークスペースの切り替え |
| `Leader + $` | ワークスペース名の変更 |
| `Leader + Shift + w` | 新しいワークスペースの作成 |

---

## タブ操作

| キー | 説明 |
|------|------|
| `Leader + {` | タブを左に移動 |
| `Leader + }` | タブを右に移動 |
| `Cmd + 1` ~ `Cmd + 8` | 指定した番号のタブに切り替え |
| `Cmd + 9` | 最後のタブに切り替え |

---

## ペイン操作

| キー | 説明 |
|------|------|
| `Ctrl + Shift + [` | ペイン選択モード |
| `Leader + z` | ペインのズーム切り替え（全画面表示） |

---

## ペイン移動（キーテーブルモード）

`Leader + a` で移動モードに入る（1秒タイムアウト）

| キー | 説明 |
|------|------|
| `h` | 左のペインに移動 |
| `l` | 右のペインに移動 |
| `k` | 上のペインに移動 |
| `j` | 下のペインに移動 |

---

## コピーモード内の操作

### 移動

| キー | 説明 |
|------|------|
| `g` | スクロールバックの先頭に移動 |
| `G` | スクロールバックの最後に移動 |
| `H` | ビューポート上部に移動 |
| `M` | ビューポート中央に移動 |
| `L` | ビューポート下部に移動 |

### ジャンプ

| キー | 説明 |
|------|------|
| `f` + 文字 | 次の指定文字にジャンプ |
| `F` + 文字 | 前の指定文字にジャンプ |
| `t` + 文字 | 次の指定文字の直前にジャンプ |
| `T` + 文字 | 前の指定文字の直後にジャンプ |
| `;` | 直前のジャンプを同じ方向に繰り返す |
| `,` | 直前のジャンプを逆方向に繰り返す |

#### スクロール

| キー | 説明 |
|------|------|
| `Ctrl + f` | 1ページ下にスクロール |
| `Ctrl + b` | 1ページ上にスクロール |
| `Ctrl + d` | 半ページ下にスクロール |
| `Ctrl + u` | 半ページ上にスクロール |

#### 選択

| キー | 説明 |
|------|------|
| `o` | 選択範囲の反対側に移動 |
| `O` | 選択範囲の反対側（水平）に移動 |

---

## フォント

| キー | 説明 |
|------|------|
| `Ctrl + 0` | フォントサイズをリセット |

---

## その他

| キー | 説明 |
|------|------|
| `Cmd + p` | コマンドパレットを表示 |
| `Ctrl + Shift + p` | コマンドパレットを表示 |
| `Opt + Enter` | フルスクリーン切り替え |
| `Ctrl + Shift + r` | 設定を再読み込み |
| `Shift + Enter` | 改行を送信 |
